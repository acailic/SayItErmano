# Historical ADW implementation plans

Implementation plans produced by the SSSF/ADW factory pipeline, keyed by
request hash. **Historical archive**: the canonical, validated record of
what shipped is `requests/*.md` (STATUS headers) plus git history — these
plans are kept for provenance only. Superseded `_v2.._v4` drafts were
removed; each plan's final version is here.

The factory itself now lives under `tools/factory/` (org plan 2.4).
