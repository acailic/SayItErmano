# Fresh-VM install matrix — paid-launch QA gate (#14)

Generated by `scripts/qa_matrix.py` — do not edit by hand; rerun the harness (on the VM) to refresh. One evidence JSON sits next to this page per route x distro; SKIPPED rows carry the reason and are the owner's fresh-VM worklist.

## How a row is run

1. Provision a FRESH VM of the distro (no prior SayItErmano install) — GPU machine and a CPU-only machine per route.
2. Clone the repo at the release commit and run `python3 scripts/qa_matrix.py` — it runs every route the VM can exercise and writes evidence next to this page.
3. Do the manual steps (dictation on both machines) and fill the row's `notes`.
4. Update to the NEXT release when it ships (the update command per route is in the checklist below), rerun, commit.

## Red-row policy

Zero ❌ rows at a paid launch. Every red row must be fixed or documented as a known issue **with a workaround** in the install guide ([docs/guides/install.md](../../guides/install.md)) before release. `scripts/qa_matrix.py --check` fails while a red row or a missing evidence file exists.

## Fresh-VM checklist (owner)

Per row: install → onboarding opens once on first `sayit-ermano app` launch (finish the 3-second tryout) → dictate on the GPU machine AND the CPU machine → update to the next release → rerun the harness and commit evidence.

### Ubuntu 24.04

- **one-shot installer (user-space)** — install: `curl -fsSL https://raw.githubusercontent.com/acailic/SayItErmano/linux/scripts/install-one-shot.sh | bash`; update: `curl -fsSL https://raw.githubusercontent.com/acailic/SayItErmano/linux/scripts/install-one-shot.sh | bash -s -- --update`
- **one-shot installer (--system)** — install: `curl -fsSL https://raw.githubusercontent.com/acailic/SayItErmano/linux/scripts/install-one-shot.sh | bash -s -- --system`; update: `curl -fsSL https://raw.githubusercontent.com/acailic/SayItErmano/linux/scripts/install-one-shot.sh | bash -s -- --system --update`
- **official .deb + signed apt repo** — install: `curl -LO <releases>/sayit-ermano_<ver>-1_amd64.deb && sudo apt install ./sayit-ermano_*.deb`; update: `sudo apt update && sudo apt upgrade sayit-ermano`
- **pipx (any distro)** — install: `pipx install sayit-ermano`; update: `pipx upgrade sayit-ermano`
- **Flatpak from Flathub** — install: `flatpak install flathub io.github.acailic.SayItErmano`; update: `flatpak update io.github.acailic.SayItErmano`
