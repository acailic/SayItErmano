## Shared install snippet (copy verbatim)

```bash
# Ubuntu 24.04 (amd64) — signed apt channel
curl -fsSL https://acailic.github.io/SayItErmano/apt/key.asc \
  | sudo gpg --dearmor -o /etc/apt/keyrings/sayit-ermano.gpg
echo "deb [signed-by=/etc/apt/keyrings/sayit-ermano.gpg] \
https://acailic.github.io/SayItErmano/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/sayit-ermano.list
sudo apt update && sudo apt install sayit-ermano
```

## Show HN

Title options (pick one):

1. Show HN: SayItErmano — local voice dictation for Linux with offline AI polish
2. Show HN: I ported a macOS dictation app to Linux; it runs entirely offline

Body:

I maintain SayItErmano, a Linux voice-dictation app: push a hotkey,
speak, and the text lands wherever your cursor is — then a local AI
pass cleans it up (fillers, punctuation, capitalization). Speech runs
on faster-whisper/Parakeet locally; the polish pass runs on a bundled
llama-server with a small GGUF chat model, so the whole loop works
with the network cable pulled out.

What shipped today (v0.9.0):

- Full UI translations (Serbian Latin/Cyrillic, Bosnian) on top of
  English, switchable at runtime.
- Wayland/Flatpak text insertion through the desktop portal input
  interface — no uinput permissions required in the default sandbox.
- A signed apt repository for Ubuntu 24.04 plus a self-update channel
  for deb installs.
- Offline license keys end to end (purchase → key → activation), for
  the paid tier we are preparing.
- A fresh-VM install QA gate and a soak/upgrade rehearsal harness in
  CI, because a paid product has to survive its own updates.

GPL-3.0, source at https://github.com/acailic/SayItErmano. Happy to
talk dictation latency, Whisper model trade-offs, or Wayland input
hacks — the last one cost me the most sleep.

## r/linux post

Title: SayItErmano v0.9.0 — offline voice dictation with local AI polish (X11 + Wayland, deb + apt repo)

Body:

v0.9.0 of SayItErmano is out. It is a local dictation tool: hold a
hotkey, speak, release — text is inserted at your cursor, then an
optional local AI pass fixes fillers and punctuation. Everything runs
on-device: faster-whisper/Parakeet for speech, a bundled llama-server
with a small GGUF model for polish. No account, no telemetry.

New in this release:

- Serbian (Latin + Cyrillic) and Bosnian UI translations, runtime
  switchable.
- Portal-based insertion on Wayland (works inside the Flatpak sandbox
  without uinput).
- Signed apt repo for Ubuntu 24.04 + self-update for deb installs.
- Offline license-key machinery for the upcoming paid tier.

Install snippet: see "Shared install snippet" above.

Known limits, stated plainly: Ubuntu 24.04/Python 3.12 is the pinned
deb target (the app itself is pure Python and runs from source
elsewhere), the AI polish model is a small one by default, and the
Flathub listing is submitted but not live yet.
